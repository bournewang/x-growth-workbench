# X涨粉工作台

当前收费安装包为 **0.9.1**，适用于 Chrome 的 X 网页版。插件把评论阅读、筛选和本浏览器中的发布／关注记录放在一起；启用后同页评论侧栏默认开启，不需要另装 SideX。

## 当前功能

- 在 X 首页点击帖子时，于页面右侧展开评论列表，主页时间线保留在原位；侧栏可以关闭、拖动宽度、恢复默认宽度，也可以进入二级回复。
- 评论顶部可分别开启「只看未关注」和「只看蓝 V」，两个条件可以同时使用。未关注筛选排除自己的评论、已关注的人和已发送关注请求的人；关注状态不明确的作者不会被当作未关注。筛选使用已经加载的 TweetDetail 作者资料，不为筛选额外请求资料卡。
- 不主动预加载用户资料卡。鼠标移到头像时才显示 X 原生资料卡，用户自行点击卡上的原生关注按钮；插件不批量关注。侧栏中的关注操作成功后会更新筛选和今日关注记录。
- 弹窗并列显示发布数与今日关注记录。发布分原创／引用、评论、转发，可查看今天或近 3／7 天；关注以 **400 次记录**为提醒参考，并在接近或达到时提示。工具栏角标显示发布数，两项记录均支持手动补记，数据按 X 账号保存在本机 Chrome 中。
- 关注计数观察本浏览器的 X 页面和侧栏发出的成功关注请求，并避免同一请求被两条观察路径重复计数；失败请求、取消关注不计。X 原生回关请求成功且返回用户 ID 与目标一致时也会计入。数字表示记录到的关注操作次数，不保证最终关注关系，也不等于独立用户数；安装前、其他设备或浏览器未运行时的操作无法自动补齐。
- X 返回限流错误时，侧栏显示明显的提示及重试入口。插件不移除 X 的嵌入安全响应头；X 更改网页或接口、限制请求频率时，相关功能可能受影响。

侧栏语言优先采用 X 页面语言。回复默认使用侧栏编辑器，翻译使用 X，二级回复默认预览 1 条。弹窗目前为中文界面；其中没有侧栏开关或阅读设置。

## 安装与更新

1. 下载并解压 [X涨粉工作台 0.9.1 收费安装包](dist/X涨粉工作台-0.9.1.zip)。
2. 在 `chrome://extensions` 开启开发者模式，选择「加载已解压的扩展程序」，选解压后的 **extension** 文件夹。更新已有安装时，覆盖**原安装目录**后点击「重新加载」，以保留原扩展 ID 和本地计数；不要从另一个目录重复安装。
3. 刷新已打开的 X 页面，首次使用自动开始 **3 天免费试用**，无需激活码。试用结束后插件功能锁定，点击扩展图标输入购买后的激活码，再刷新 X 继续使用。若另装了 SideX，请停用它，以免两个侧栏同时接管页面。

## 免费试用

试用从首次打开 X（包含 X Pro）开始，持续 72 小时。打开弹窗、安装或重载本身不会开始试用；试用中可提前输入付费激活码。到期后计数、补记、侧栏请求及翻译被锁定，数据保留。已经打开的侧栏最多 30 秒内关闭，发起下一次请求前也会检查授权。

0.8.2 的试用记录保存在本机。**0.9.0** 改为服务端登记试用：首次试用需要联网，同一匿名安装不会因删除本地试用时间而重新计时；已有本地试用迁移时保留原到期时间。卸载并生成新的安装身份仍可能重复试用，不能等同于按真实用户防重复。付费授权的在线校验机制保持不变。

## 激活码与会员期限

收费包连接已部署的 Cloudflare Worker + D1 激活服务。买家在插件中只输入激活码；购买邮箱用于发码记录和售后查询，不在插件中填写或随每次验证发送。首次激活绑定一个浏览器安装 ID。服务端保存邮箱、订单信息、授权状态和到期时间；激活码只保存摘要，不保存可查询的明文。

新码默认从发放时起有效 **3 天**，发码时可指定天数、月数、永久授权或准确到期时间。当前套餐为 1 个月 ¥28、3 个月 ¥78、6 个月 ¥128、1 年 ¥198，微信联系购买后人工发码。Worker 在激活和续验时校验到期时间。客户端可短期缓存在线验证结果；离线宽限最多 7 天，但不会越过已知到期时间。迁移前发出的旧码保留原有效期。

续费更新原授权的到期日，原码和设备绑定不变；补发只换码，默认保留原到期日，不会自动延长会员。永久授权没有到期日。发码、查询、解绑、补发、续费、停用的操作方法见 [激活码服务说明](license-server/README.md)。管理密钥只放在 Worker Secret 和卖家本机钥匙串中，不随安装包分发。

### 生成指定有效期的激活码（卖家操作）

以下命令均在**项目根目录**运行。将 `buyer@example.com` 替换为买家的购买邮箱，订单号替换为实际订单号。工具默认连接已部署的激活服务，并从卖家本机 macOS 钥匙串读取管理密钥；不需要在命令里填写密钥。

```sh
# 1 个月（¥28）
node license-server/admin.mjs issue --email buyer@example.com --months 1 --order ORDER-001

# 3 个月（¥78）
node license-server/admin.mjs issue --email buyer@example.com --months 3 --order ORDER-002

# 6 个月（¥128）
node license-server/admin.mjs issue --email buyer@example.com --months 6 --order ORDER-003

# 1 年（¥198，按 12 个日历月计算）
node license-server/admin.mjs issue --email buyer@example.com --months 12 --order ORDER-004

# 自定义天数：例如有效 10 天
node license-server/admin.mjs issue --email buyer@example.com --days 10

# 指定北京时间的到期时刻：2027 年 12 月 31 日 23:59:59
node license-server/admin.mjs issue --email buyer@example.com --expires-at '2027-12-31T23:59:59+08:00'

# 永久授权（无到期日）
node license-server/admin.mjs issue --email buyer@example.com --plan permanent
```

- **从发码时开始计时，不是从买家首次激活时开始。** 月数按 UTC 日历月顺延，月末自动取目标月最后一天；需要精确到当地日期时，请使用带时区的 `--expires-at`。
- `--days`、`--months`、`--expires-at`、`--plan` **一次只选一种**。天数范围 1–3650，月数范围 1–120，指定到期时刻必须在未来。`--order` 可省略。
- 成功后终端返回 `code`（交付买家的激活码）、`licenseId`（售后使用的授权 ID）和 `expiresAt`（到期时间戳）；`expiresAtLocal` 按运行电脑的本地时区显示。永久授权的 `expiresAt` 为 `null`。
- **明文激活码只在发放或补发时返回一次。** 请安全交付并保留订单与授权 ID；不要把真实激活码或管理密钥提交到仓库。
- 不指定期限时，新码默认仅有效 3 天。插件自带的 3 天免费试用无需发码，与这里的付费授权相互独立。
- `issue` 每次都会生成一个新码。已有用户续费请使用 `renew`，保留原码和设备绑定：

```sh
# 先按邮箱查询 license_id（查询不会返回激活码明文）
node license-server/admin.mjs lookup --email buyer@example.com

# 将授权ID替换为查询结果中的 license_id，给原授权续费 1 个月
node license-server/admin.mjs renew --email buyer@example.com --license 授权ID --months 1
```

按天或按月续费从“当前到期日与现在较晚者”起计算；更完整的解绑、补发、停用说明见 [激活码服务说明](license-server/README.md)。
