# X涨粉工作台

当前收费安装包为 **0.8.1**，适用于 Chrome 的 X 网页版。插件把评论阅读、筛选和本浏览器中的发布／关注记录放在一起；启用后同页评论侧栏默认开启，不需要另装 SideX。

## 当前功能

- 在 X 首页点击帖子时，于页面右侧展开评论列表，主页时间线保留在原位；侧栏可以关闭、拖动宽度、恢复默认宽度，也可以进入二级回复。
- 评论顶部可分别开启「只看未关注」和「只看蓝 V」，两个条件可以同时使用。未关注筛选排除自己的评论、已关注的人和已发送关注请求的人；关注状态不明确的作者不会被当作未关注。筛选使用已经加载的 TweetDetail 作者资料，不为筛选额外请求资料卡。
- 不主动预加载用户资料卡。鼠标移到头像时才显示 X 原生资料卡，用户自行点击卡上的原生关注按钮；插件不批量关注。侧栏中的关注操作成功后会更新筛选和今日关注记录。
- 弹窗并列显示发布数与今日关注记录。发布分原创／引用、评论、转发，可查看今天或近 3／7 天；关注以 **400 次记录**为提醒参考，并在接近或达到时提示。工具栏角标显示发布数，两项记录均支持手动补记，数据按 X 账号保存在本机 Chrome 中。
- 关注计数观察本浏览器的 X 页面和侧栏发出的成功关注请求，并避免同一请求被两条观察路径重复计数；失败请求、取消关注不计。X 原生回关请求成功且返回用户 ID 与目标一致时也会计入。数字表示记录到的关注操作次数，不保证最终关注关系，也不等于独立用户数；安装前、其他设备或浏览器未运行时的操作无法自动补齐。
- X 返回限流错误时，侧栏显示明显的提示及重试入口。插件不移除 X 的嵌入安全响应头；X 更改网页或接口、限制请求频率时，相关功能可能受影响。

侧栏语言优先采用 X 页面语言。回复默认使用侧栏编辑器，翻译使用 X，二级回复默认预览 1 条。弹窗目前为中文界面；其中没有侧栏开关或阅读设置。

## 安装与更新

1. 下载并解压 [X涨粉工作台 0.8.1 收费安装包](dist/X涨粉工作台-0.8.1.zip)。
2. 在 `chrome://extensions` 开启开发者模式，选择「加载已解压的扩展程序」，选解压后的 **extension** 文件夹。更新已有安装时，覆盖**原安装目录**后点击「重新加载」，以保留原扩展 ID 和本地计数；不要从另一个目录重复安装。
3. 点击扩展图标输入购买后的激活码，随后刷新已打开的 X 页面。若另装了 SideX，请停用它，以免两个侧栏同时接管页面。

## 激活码与会员期限

收费包连接已部署的 Cloudflare Worker + D1 激活服务。买家在插件中只输入激活码；购买邮箱用于发码记录和售后查询，不在插件中填写或随每次验证发送。首次激活绑定一个浏览器安装 ID。服务端保存邮箱、订单信息、授权状态和到期时间；激活码只保存摘要，不保存可查询的明文。

新码默认从发放时起有效 **3 天**，发码时也可指定 3 个月、6 个月、永久授权或准确到期时间；具体售价尚未设置。Worker 在激活和续验时校验到期时间。客户端可短期缓存在线验证结果；离线宽限最多 7 天，但不会越过已知到期时间。迁移前发出的旧码保留原有效期。

续费更新原授权的到期日，原码和设备绑定不变；补发只换码，默认保留原到期日，不会自动延长会员。永久授权没有到期日。发码、查询、解绑、补发、续费、停用的操作方法见 [激活码服务说明](license-server/README.md)。管理密钥只放在 Worker Secret 和卖家本机钥匙串中，不随安装包分发。

## 开发与验证

`extension/` 是开发源码，激活开关默认关闭；其 `manifest.json` 保留开发基线版本号 **0.7.4**。`npm run build:paid -- https://x-growth-license.xiaopei0206.workers.dev` 会复制源码，生成开启激活的 **0.8.1** 安装包并写入相应版本号与 Worker 权限。不要把源码目录直接作为收费包交付。

`npm test` 运行逻辑测试；`node tests/browser.cjs` 和 `node tests/sidex-browser.cjs` 使用 Playwright、Chromium、OpenSSL 在本机模拟 X 页面，不登录真实账号。激活服务的本地端到端检查见 [服务端说明](license-server/README.md)，更多验证记录见 [VALIDATION.md](VALIDATION.md)。
